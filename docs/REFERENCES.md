# Официальные источники

Проверено при подготовке стартового пакета: 25 октября 2026 года.
Перед установкой Codex должен дополнительно проверить совместимость выбранных версий.
Источники объясняют инструменты; бизнес-правила этого проекта — наши проектные решения,
а не утверждения производителей фреймворков.

- OpenAI, AGENTS.md: https://developers.openai.com/codex/agent-configuration/agents-md
- OpenAI, Codex CLI: https://developers.openai.com/codex/cli
- OpenAI, Codex best practices: https://developers.openai.com/codex/learn/best-practices
- pnpm workspaces: https://pnpm.io/workspaces
- Next.js installation: https://nextjs.org/docs/app/getting-started/installation
- NestJS validation: https://docs.nestjs.com/application/validation
- TypeORM migrations: https://typeorm.io/docs/migrations/why/
- TypeORM migration setup: https://typeorm.io/docs/migrations/setup/
- FullCalendar Premium: https://fullcalendar.io/docs/premium

Root AGENTS.md содержит постоянные инструкции агента; отдельные prompts задают scope этапа.
Для pnpm monorepo используется корневой pnpm-workspace.yaml.
TypeORM migrations работают с выключенной автоматической синхронизацией схемы.
FullCalendar resource/timeline plugins имеют отдельные условия лицензирования.
